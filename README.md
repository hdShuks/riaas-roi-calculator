# RiaaS Road Survey Calculator

A single-page calculator for Texas county road engineers. Enter your road miles to see what Dareesoft RiaaS would cost and how often you'd inspect every road.

Everything lives in `index.html` (plain HTML, CSS and JS). No build step.

## Deploy on Vercel

1. In Vercel, click **Add New > Project** and import this GitHub repo.
2. Set **Framework Preset** to **Other**.
3. Leave **Build Command** empty and **Output Directory** as the default (repo root).
4. Click **Deploy**.

Every push to `main` redeploys automatically.

## Run locally

Open `index.html` in a browser.
